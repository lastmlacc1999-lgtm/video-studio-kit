The browser app writes a timed, scene-by-scene script with Gemini, GPT or a local model. Your key stays in this browser. When you are ready to render, hand the project to the local studio — rendering needs ffmpeg, the style skills and this computer.

  • 1. Pick a style and describe your idea.
  • 2. Write the script, then edit every scene.
  • 3. Render with the local studio, or download the project.

No studio server? The app still writes and stores scripts. Open /app/ from the studio (default http://localhost:4790) to render here.
